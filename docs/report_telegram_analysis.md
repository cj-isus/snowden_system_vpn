## 8. 🔑 Ключевые выводы

1. **Активное сообщество** по обходу блокировок: обсуждаются белые/чёрные списки РКН, блокировки по DPI, отвалы VPN.
2. **Основные направления обхода:**
   - **Чёрные списки:** AmneziaWG + WARP, Clash/Mihomo с MASQUE, mieru, VLESS+Reality.
   - **Белые списки:** WDTT / SRTP через VK-звонки, TURN-прокси, Yandex Cloud / VK Cloud серверы.
   - **Локальный обход:** zapret, ByeByeDPI, Firefox VPN.
3. **Инфраструктура:** Используются релей-серверы (tribukvy.ltd, openwarpkit), VPS-хостеры (NodeHost, Hetzner, DigitalOcean, Vultr, Eternity, Shinomiya, FirstByte, AdminVPS).
4. **Конфигурации:** Найдены готовые WG/AWG конфиги (ANTIDOT-X-PRO, SmartTv2), Clash-профиль с MASQUE, SQLite-база с 8 WG-туннелями.
5. **Безопасность данных:** В SQLite и .conf-файлах присутствуют приватные ключи WireGuard, IP-адреса, endpoint'ы — данные чувствительные.
