КАК ПОЛЬЗОВАТЬСЯ:
─────────────────
1. Дважды кликни на snowden-system.exe
2. Откроется окно с дашбордом
3. Нажми большую кнопку ВКЛ (или ⏻ в правом верхнем углу)
4. Подожди 5-10 секунд — загорится зелёным "ЗАЩИЩЁН"
5. Всё! Telegram, YouTube, Discord работают

ВЫКЛЮЧЕНИЕ:
──────────
  Нажми кнопку ⏻ ВЫКЛ. Прокси снимется автоматически.

ПРОБЛЕМЫ?
─────────
  • Не работает интернет → выключи и включи VPN
  • Медленно → см. карточку "Серверы", возможно высокий пинг
  · Банк не работает → он идёт напрямую, проверь мобильный интернет
