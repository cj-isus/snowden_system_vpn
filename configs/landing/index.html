💻 ПК (Windows) — полная инструкция

Установка

  1. Скачать ZIP (15 МБ) с этой страницы
  2. Распаковать в любую папку
  3. Запустить snowden-system.exe
  4. Нажать кнопку ВКЛ (большая зелёная кнопка)
  5. Дождаться статуса «ЗАЩИЩЁН»
Не требует прав администратора. Работает из любой папки.

Интерфейс

Раздельное туннелирование

Российские сайты (.ru, .su, .рф + 245 доменов) идут напрямую — без VPN. Банки, Госуслуги, ВКонтакте, Яндекс, Авито, Ozon.

Заблокированные (YouTube, Telegram, Discord, ChatGPT) — через VPN.

Circuit Breaker

Health-check каждые 30 сек. Если туннель падает — автоматическое переподключение. 3 состояния: HEALTHY → FAILED → RECOVERING.

Telegram-бот

Приложение отправляет отчёты в Telegram при ошибках (не чаще раза в час). Админ-панель с inline-кнопками:

  • /status — состояние VPN
  • /servers — список серверов с пингом
  • /traffic — трафик сессии
  • /reconnect — переподключить
  • /logs — последние логи
  • /devices — список устройств
  • /pc /apk /ios — скачать файлы

Обновление

Settings → «Проверить обновления». Если есть новая версия — откроется эта страница.

Решение проблем

  • VPN не подключается — закройте и откройте приложение. Cache.db очищается автоматически.
  • Нет интернета после выключения VPN — прокси очищается автоматически (crash handler). При перезапуске — stale proxy cleanup.
  • Медленно — проверьте ServersCard. urltest выбирает лучший сервер автоматически.

📱 Android — полная инструкция

Установка

  1. Скачать APK (110 МБ)
  2. Открыть APK → разрешить установку из этого источника
  3. Открыть snowden.system → нажать ПОДКЛЮЧИТЬ
  4. Разрешить VPN (системный диалог) — готово
⚠️ Если APK не ставится: Настройки → Спецдоступ → Установка из неизвестных источников → разрешить браузер.

Важно: другие VPN

Android разрешает только один VPN одновременно. Перед подключением snowden.system отключите Amnezia VPN, WireGuard,或其他 VPN-приложения. Если Amnezia работает в фоне — остановите её: Настройки → Приложения → Amnezia → Остановить.

Кнопка в шторке (Quick Settings Tile)

  1. Шторка вниз дважды
  2. ✏️ карандаш / «Изменить»
  3. Найти плитку «snowden.system»
  4. Перетащить в активную зону

Банки не видят VPN

90+ российских приложений полностью исключены из VPN (addDisallowedApplication). Их трафик идёт напрямую через физический интерфейс — банк видит обычный российский IP, а не VPN.

Исключены: Сбер, Т-Банк, ВТБ, Альфа, РСХБ, Газпромбанк, МКБ, ПСБ, Открытие, Хоум Кредит, ОТП, Райффайзен, Росбанк, Совкомбанк, Ак Барс, ВкусВилл, Ozon, Wildberries, Авито, ВКонтакте, Mail.ru, Яндекс (12 сервисов), Госуслуги, МТС, Билайн, Мегафон, Tele2, Кинопоиск, 2ГИС и др.

Настройки (⚙️ в шапке)

  • Раздельное туннелирование — вкл/выкл (.ru напрямую)
  • Hysteria2 — вкл/выкл UDP протокол
  • Telegram-отчёты — статус VPN в Telegram-бот
  • Отправить логи — кнопка ✈️ в панели логов, отправляет логи в Telegram

Выбор сервера

В Настройках можно выбрать сервер вручную: Авто / Нидерланды / Франция. По умолчанию — Авто (urltest выбирает лучший).

Обновление

Иконка 🔔 в шапке если есть обновление. Или скачайте свежий APK.

Альтернативный способ: sing-box из Play Store

Скачайте конфиг «sing-box Android» выше. Установите sing-box из Play Store. Откройте файл конфига через sing-box → Connect.

🍎 iOS (iPhone) — инструкция

Способ 1: sing-box (App Store, бесплатно)

  1. App Store → найти и установить sing-box (бесплатно)
  2. Скачать конфиг «iOS» вверху страницы
  3. Открыть файл snowden-ios-config.json через sing-box
  4. Разрешить VPN (системный диалог)
  5. Нажать Connect

  1. App Store → найти и установить Karing (бесплатно)
  2. Скачать конфиг «sing-box Android» вверху страницы (тот же формат)
  3. Открыть файл snowden-android-singbox.json через Karing
  4. Разрешить VPN → нажать Start
ℹ️ Собственное iOS-приложение требует Mac + Apple Developer ($99/год). Бесплатная альтернатива — sing-box или Karing с нашим конфигом.

Что работает через VPN

Telegram, YouTube, Discord, ChatGPT, Instagram, Netflix — всё заблокированное.

Что идёт напрямую

Российские сайты (.ru, банки, Госуслуги) — через split-tunneling в конфиге. Банковские приложения работают без детекции VPN.

Отличия от Android-версии

  • Нет банковских исключений по пакетам (iOS не поддерживает) — только по доменам
  • Нет кнопки в шторке (iOS не поддерживает)
  • Нет Telegram-репортера

🛡 Amnezia VPN — альтернативный способ

Установка

  1. Скачать Amnezia VPN с amnezia.org (Windows, Android, iOS)
  2. Скачать конфиг «Amnezia VPN» вверху страницы (snowden-amnezia.conf)
  3. Открыть Amnezia VPN → Настройки → Импорт → выбрать скачанный файл
  4. Нажать Подключить
⚠️ Amnezia и snowden.system не могут работать одновременно — Android/iOS разрешают только один активный VPN. Выключите одно перед включением другого.

Что это даёт

WARP (Cloudflare AmneziaWG) — бесплатный VPN с обфускацией трафика. Обходит блокировки РКН через протокол WireGuard с дополнительными параметрами (jc, jmin, jmax, h1-h4), которые маскируют пакеты.

Что работает

  • Telegram, YouTube, Discord — через Cloudflare WARP
  • Российские сайты — напрямую (если настроить маршрутизацию в Amnezia)

🔧 Как это работает (технически)

Архитектура

sing-box-lx (embedded Go library) — VLESS+TLS с настоящим Let's Encrypt сертификатом. Для ТСПУ (DPI Роскомнадзора) выглядит как обычный HTTPS.

2 сервера с авто-failover

СерверIPЛокацияsing-boxBBR
NLYOUR_VPS_IPНидерландыlx 1.14.0✅
FRYOUR_VPS_IPФранция1.13.14✅

7 outbound'ов в urltest

Каждые 30 сек sing-box проверяет все 7 outbound'ов и выбирает лучший (tolerance 50ms):

gRPC NL → gRPC FR → HTTPUpgrade NL → HTTPUpgrade FR → VLESS NL → VLESS FR → Hysteria2

Анти-ТСПУ защита

  • gRPC — binary framing, максимальная скорость
  • HTTPUpgrade — маскировка под WebSocket upgrade
  • Firefox uTLS — TLS fingerprint Firefox (не Go)
  • BBR — congestion control на серверах (стабильная latency)

DNS

Split resolver: российские домены → системный DNS (быстро), VPN-домены → DoH 1.1.1.1 через туннель (защита от DPI подмены).

Split-tunneling

245+ российских доменов → direct (мимо VPN). На Android — 90+ приложений исключены через addDisallowedApplication.

Circuit Breaker (ПК)

3 состояния: HEALTHY (Closed) → FAILED (Open) → RECOVERING (HalfOpen). Health-check каждые 30 сек через deepProbe. Авто-Reload при сбое.

Стабильность (ПК)

  • Crash handler — SetConsoleCtrlHandler очищает прокси при Ctrl+C/Taskkill
  • Stale proxy cleanup — при старте проверяет реестр на мёртвый прокси
  • Cache.db auto-cleanup — удаляется перед каждым стартом sing-box
  • Panic recovery — engine.Start() обёрнут в defer recover()

Сборка

ПК:     wails build -tags "with_awg,with_wireguard,with_utls,with_gvisor"
Android: flutter build apk --release
Деплой:  python deploy.py

🚨 Решение проблем

ПК: VPN не подключается

  • Закройте и откройте приложение
  • Удалите файл cache.db рядом с snowden-system.exe
  • Проверьте что нет другого VPN запущенного

ПК: Нет интернета после выключения VPN

Прокси очищается автоматически. Если не помогло — Пуск → Настройки → Сеть → Прокси → Отключить.

Android: VPN не включается

  • Отключите Amnezia VPN и другие VPN-приложения
  • Настройки → Приложения → Amnezia → Остановить
  • Перезапустите snowden.system

Android: Банки ругаются на VPN

Убедитесь что в приложении включён split-tunnel (⚙️ → Раздельное туннелирование). 90+ приложений исключены автоматически.

Медленная скорость

urltest автоматически выбирает лучший сервер. Проверьте ServersCard — если все серверы с высоким пингом, возможно проблема с интернет-провайдером.

Отправка логов

Android: откройте панель логов (терминал в шапке) → нажмите ✈️ (Отправить в Telegram).

ПК: внизу окна панель логов → выделите мышью → Ctrl+C. Или Telegram-бот → /logs.
