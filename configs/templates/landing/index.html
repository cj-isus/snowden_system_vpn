💻 ПК — инструкция

  1. Скачать ZIP
  2. Распаковать
  3. Запустить exe
  4. Нажать ВКЛ

📱 Android — инструкция

  1. Скачать APK
  2. Установить (разрешить неизвестные источники)
  3. Открыть → нажать ПОДКЛЮЧИТЬ

Или: установить sing-box из Play Store → скачать конфиг → импорт

🍎 iOS — инструкция

  1. App Store → установить sing-box или Karing
  2. Скачать конфиг выше
  3. Открыть файл через sing-box / Karing
  4. Connect

🛡 Amnezia VPN

  1. Скачать Amnezia VPN (amnezia.org)
  2. Скачать конфиг выше
  3. Settings → Import → выбрать файл
  4. Connect
⚠️ Amnezia и основной VPN не могут работать одновременно.
