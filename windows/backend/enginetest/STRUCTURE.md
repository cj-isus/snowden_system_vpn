# STRUCTURE.md — backend/enginetest

> Пакет `main` (исполняемый прогон, НЕ `_test.go`). Ручной e2e-тест движка.

## Назначение
Собирается отдельным бинарником, поднимает sing-box на тестовом конфиге
(`test-reality-20810.json`) и проверяет: запуск, скорость (10MB с
`speed.cloudflare.com`), доступность `t.me`. Нужен для локали багов без GUI.

## Файлы
| Файл | Роль | Ключевые символы |
|------|------|-------------------|
| `e2e.go` | Точка входа `main()` | `h` (реализует `core.LogHandler`), печать логов, HTTP-пробы через `127.0.0.1:20810` |

## Ручной запуск
```bash
cd windows
go run ./backend/enginetest        # ждёт конфиг build/bin/assets/configs/test-reality-20810.json
```
(Путь к конфигу захардкожен — при запуске из другого места укажи/поправь путь.)

## Потоки данных
`os.ReadFile(конфиг)` → `core.NewEngine()` + `SetLogHandler` → `engine.Start(cfg)`
→ HTTP-клиенты через прокси `127.0.0.1:20810` → speed + t.me → `defer engine.Close()`.

## Нюансы
- Это не автоматизированный тест в CI; ассертов/возврата кода нет — смотри stdout.
- Использует порт `20810` (не 20808) — не конфликтует с основным приложением.
