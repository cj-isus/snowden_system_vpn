# snowden.system

Greenfield-проект защищённого клиента для Windows и Android.

Главный источник правды: [`PLAN.md`](PLAN.md). Перед любой работой, особенно
после сжатия контекста, его нужно перечитать. В плане находятся требования,
решения, статусы, блокеры и дневник разработки.

Внешние open-source аналоги, которые изучаются до реализации, перечислены в
[`references/`](references/README.md).

iOS не входит в scope проекта.
